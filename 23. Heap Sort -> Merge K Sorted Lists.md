# 23.Merge K Sorted Lists Notes

## 📌 Problem

You are given `k` sorted linked lists.
Merge them into **one sorted linked list**.

Example:

```
Input: [[1,4,5], [1,3,4], [2,6]]
Output: [1,1,2,3,4,4,5,6]
```

👉 Each list is already sorted → we must **merge efficiently**, not re-sort everything. ([Beizhedenglong][1])

---

## 🧠 Core Idea

Use a **Min Heap (Priority Queue)**

* Always pick the **smallest node among all lists**
* Push next node from same list after removing one

This gives optimal complexity:

```
Time → O(N log K)
Space → O(K)
```

Because heap size is at most `k` (number of lists) ([Hello Interview][2])

---

## ⚙️ Python Code (LeetCode Style)

```python
import heapq

class Solution:
    def mergeKLists(self, lists):
        minHeap = []

        # Step 1: Push first node of each list
        for i in range(len(lists)):
            if lists[i]:
                heapq.heappush(minHeap, (lists[i].val, i, lists[i]))

        dummy = ListNode(0)
        curr = dummy

        # Step 2: Process heap
        while minHeap:
            val, i, node = heapq.heappop(minHeap)

            curr.next = node
            curr = curr.next

            if node.next:
                heapq.heappush(minHeap, (node.next.val, i, node.next))

        return dummy.next
```

# 🔍 Line-by-Line Explanation

---

### 🔹 `import heapq`

* Python library for **min-heap**
* Automatically keeps smallest element on top

---

### 🔹 `minHeap = []`

* Empty heap
* Will store:

```
(value, list_index, node)
```

👉 Why tuple?

* Heap compares by first value (smallest number)
* `list_index` avoids comparison errors
* `node` stores actual linked list node

---

### 🔹 Loop: Push first nodes

```python
for i in range(len(lists)):
    if lists[i]:
        heapq.heappush(minHeap, (lists[i].val, i, lists[i]))
```

✔ Purpose:

* Put **first element of each list** into heap

🧠 Insight:
You only keep **k elements in heap**, not all elements
→ this is why it's efficient

---

### 🔹 Dummy Node

```python
dummy = ListNode(0)
curr = dummy
```

✔ Purpose:

* Helps build result list easily
* Avoids edge cases

---

### 🔹 Main Loop

```python
while minHeap:
```

✔ Runs until heap is empty
→ means all nodes processed

---

### 🔹 Pop smallest element

```python
val, i, node = heapq.heappop(minHeap)
```

✔ Always gives **smallest value node**

---

### 🔹 Attach to result

```python
curr.next = node
curr = curr.next
```

✔ Add node to final merged list

---

### 🔹 Push next node

```python
if node.next:
    heapq.heappush(minHeap, (node.next.val, i, node.next))
```

✔ After removing one node:

* Push its next node into heap

🧠 This keeps heap updated with next smallest candidates

---

### 🔹 Return result

```python
return dummy.next
```

✔ Skip dummy node
✔ Return actual head

---

# 🧠 Mental Model

```
Step 1 → Put first elements of all lists in heap
Step 2 → Take smallest
Step 3 → Add its next element
Repeat until empty
```

---

# ⚠️ Common Mistakes

❌ Pushing all nodes into heap → becomes sorting → slow
❌ Forgetting `i` in tuple → comparison error
❌ Not handling empty lists
